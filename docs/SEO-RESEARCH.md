Researched 2026-10-06 via live web search. Goal: rank for real demand while owning the
one angle nobody else has (open-weight AI + offline + frost dates).

## What the search landscape actually looks like (verified)

### Google: frost-date space is CROWDED but AI-free
Top results for "last frost date / when to plant" are all plain calculators:
garden.org, farmergrows.com, seasonwise.app, getgrowsmart.com, gardendraft.com,
ourgardenworks.com, gardenfrostdates.com, overcalculator.com. Common phrases they rank for:
- "last spring frost date"
- "when to plant tomatoes"
- "frost date calculator"
- "planting calendar by zip code"
- "frost dates by zip code"
- "when to plant [crop]"
NONE of them use an open-weight model or run offline. That is our wedge.

### Google: "open-weight / run Gemma locally" is CROWDED with generic guides
Many 2026 posts: "Run Gemma 4 locally", "Gemma 4 local setup with Ollama". All generic
"here's how to run the model" tutorials. NONE build a real offline product with it, and
NONE pair it with TabPFN. "TabPFN" barely appears in consumer content at all.

### The open lane (our unique, rankable combination)
"TabPFN + Gemma + offline app" = effectively zero competing content. Pairing a tabular
foundation model (forecast) with a local LLM (explanation) in one offline tool is novel.
